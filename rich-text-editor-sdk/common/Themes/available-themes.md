# Available Themes

The Syncfusion Rich Text Editor includes 19+ professionally designed themes, all available as npm packages. Each theme is available in both light and dark variants, providing flexibility and accessibility for all applications.

## Theme Categories

### Modern Themes (Recommended)

These are the latest, actively maintained themes that follow current design standards:

#### Material 3

**Package**: `@syncfusion/ej2-material3-theme` / `@syncfusion/ej2-material3-dark-theme`

Material 3 is Google's latest design system featuring a dynamic color system, vibrant colors, and modern aesthetics.

- **Best For**: Modern applications, Google ecosystem projects
- **Design**: Bold colors, rounded corners, elevation effects
- **Accessibility**: WCAG AAA compliant
- **File Size**: 3.97 MB (full), 2.96 MB (lite)

**Import**:
```css
@import "@syncfusion/ej2-material3-theme/styles/material3.css";
@import "@syncfusion/ej2-material3-dark-theme/styles/material3-dark.css";
```

#### Fluent 2

**Package**: `@syncfusion/ej2-fluent2-theme` / `@syncfusion/ej2-fluent2-dark-theme`

Fluent 2 is Microsoft's design system with a modern, clean aesthetic, subtle animations, and professional appearance.

- **Best For**: Enterprise applications, Microsoft ecosystem
- **Design**: Clean lines, subtle colors, professional feel
- **Accessibility**: WCAG AAA compliant
- **File Size**: Optimized for performance

**Import**:
```css
@import "@syncfusion/ej2-fluent2-theme/styles/fluent2.css";
@import "@syncfusion/ej2-fluent2-dark-theme/styles/fluent2-dark.css";
```

#### Bootstrap 5.3

**Package**: `@syncfusion/ej2-bootstrap5.3-theme` / `@syncfusion/ej2-bootstrap5.3-dark-theme`

Bootstrap 5.3 theme aligns with the latest Bootstrap framework, providing consistency for Bootstrap-based projects.

- **Best For**: Bootstrap-based projects
- **Design**: Bootstrap-compliant, consistent with v5.3
- **Accessibility**: WCAG AA compliant
- **File Size**: Optimized and lightweight

**Import**:

#### Tailwind 3.4

**Package**: `@syncfusion/ej2-tailwind3-theme` / `@syncfusion/ej2-tailwind3-dark-theme`

Tailwind 3.4 theme is designed for projects using Tailwind CSS utility framework.

## Installation

### Install Theme Package

All themes are available on npm:

```bash
npm install @syncfusion/ej2-<theme-name>-theme --save
```

**Examples**:

```bash
# Material 3
npm install @syncfusion/ej2-material3-theme --save

# Fluent 2
npm install @syncfusion/ej2-fluent2-theme --save

# Bootstrap 5.3
npm install @syncfusion/ej2-bootstrap5.3-theme --save

# Tailwind 3.4
npm install @syncfusion/ej2-tailwind3-theme --save
```

### Install Dark Theme Variant

Dark themes are separate packages:

```bash
npm install @syncfusion/ej2-<theme-name>-dark-theme --save
```

**Example**:

```bash
npm install @syncfusion/ej2-material3-dark-theme --save
```

## Using Themes

### Method 1: Import CSS File

Import the theme CSS directly in your application:

```css
@import "@syncfusion/ej2-material3-theme/styles/material3.css";
```

### Method 2: Link HTML

Link the CSS file in your HTML:

```html
<link rel="stylesheet" href="node_modules/@syncfusion/ej2-material3-theme/styles/material3.css">
```

### Method 3: Component-Specific Import

Import CSS for specific components:

```css
@import "@syncfusion/ej2-material3-theme/styles/rich-text-editor/index.css";
```

### Method 4: Lite Version

Use optimized lite version (normal size mode only):

```css
@import "@syncfusion/ej2-material3-theme/styles/material3-lite.css";
```

## Theme Features

### Light and Dark Modes

All modern themes include both light and dark variants:

```css
/* Light mode (default) */
@import "@syncfusion/ej2-material3-theme/styles/material3.css";

/* Dark mode */
@import "@syncfusion/ej2-material3-dark-theme/styles/material3-dark.css";
```

Apply dark mode using the `.e-dark` class:

```html
<div class="e-dark">
    <ejs-richtexteditor></ejs-richtexteditor>
</div>
```

### Size Modes

Each theme supports two size modes:

- **Normal** (default) - Standard sizing for desktop and general use
- **Bigger** - Larger touch targets and spacing for touch devices

The lite versions include only the normal size mode, reducing file size.

### Color Variables

All themes expose CSS custom properties for customization:

```css
--color-sf-primary          /* Primary color */
--color-sf-secondary        /* Secondary color */
--color-sf-success          /* Success state */
--color-sf-warning          /* Warning state */
--color-sf-danger           /* Error/Danger state */
--color-sf-surface          /* Background color */
```

## Choosing the Right Theme

### Recommendation Matrix

| Scenario | Recommended Theme |
|----------|-------------------|
| Modern web application | Material 3 or Fluent 2 |
| Bootstrap project | Bootstrap 5.3 |
| Tailwind CSS project | Tailwind 3.4 |
| Enterprise application | Fluent 2 |
| Accessibility required | High Contrast |
| Mobile app | Material 3 (with bigger size mode) |
| Legacy Bootstrap project | Bootstrap 4 or Bootstrap 5 |

### Decision Flowchart

1. **Are you using Bootstrap?** → Use Bootstrap 5.3
2. **Are you using Tailwind CSS?** → Use Tailwind 3.4
3. **Do you need enterprise design?** → Use Fluent 2
4. **Do you need modern design?** → Use Material 3
5. **Is accessibility critical?** → Use High Contrast

## Theme Customization

### Customize Theme Colors

Use CSS variables to override theme colors:

```css
:root {
    --color-sf-primary: #0066cc;
    --color-sf-secondary: #00b3e6;
    --color-sf-success: #00cc66;
}
```

### Create Custom Theme

Use Theme Studio to create custom themes:

1. Visit https://ej2.syncfusion.com/themestudio
2. Select "Material 3" as base (or your preferred theme)
3. Adjust colors and export
4. Import the custom theme in your project

## Performance Optimization

### Use Lite Versions

For production, use lite versions when bigger size mode isn't needed:

```css
/* Reduces file size by ~25% */
@import "@syncfusion/ej2-material3-theme/styles/material3-lite.css";
```

### Component-Specific CSS

Import only the CSS for components you use:

```css
/* Instead of importing all themes */
@import "@syncfusion/ej2-material3-theme/styles/rich-text-editor/index.css";
```

### Lazy Load Dark Theme

Load dark theme CSS only when needed:

```javascript
function enableDarkMode() {
    const link = document.createElement('link');
    link.rel = 'stylesheet';
    link.href = 'node_modules/@syncfusion/ej2-material3-dark-theme/styles/material3-dark.css';
    document.head.appendChild(link);
}
```

## Switching Themes at Runtime

### Dynamic Theme Switching

```javascript
function switchTheme(themeName) {
    const link = document.getElementById('theme-link');
    link.href = `node_modules/@syncfusion/ej2-${themeName}-theme/styles/${themeName}.css`;
}

// Usage
switchTheme('fluent2');
```

### Toggle Dark Mode

```javascript
function toggleDarkMode() {
    document.body.classList.toggle('e-dark');
    
    // Load or remove dark theme CSS
    const darkLink = document.getElementById('dark-theme-link');
    if (document.body.classList.contains('e-dark')) {
        darkLink.disabled = false;
    } else {
        darkLink.disabled = true;
    }
}
```

## Troubleshooting

### Theme Not Applied

**Ensure CSS is loaded properly**:
- Check browser console for CSS load errors
- Verify npm package is installed
- Check file path is correct

**Clear cache and rebuild**:
```bash
npm cache clean --force
npm install
```

### Colors Not Changing

**Use CSS variables instead of hardcoding colors**:
```css
/* ❌ Avoid */
.e-richtexteditor .e-rte-content {
    color: blue; /* Won't follow theme */
}

/* ✅ Prefer */
.e-richtexteditor .e-rte-content {
    color: var(--color-sf-primary);
}
```
